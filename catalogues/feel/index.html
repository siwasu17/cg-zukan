Game feel catalogue

ゲームの手触り図鑑

同じ操作をしているのに、あるゲームは気持ちよく、別のゲームはもっさり感じる。その差の多くは、画面の揺れや一瞬の停止、ジャンプの判定の甘さなど、遊んでいる人がはっきりとは気づかない小さな工夫から生まれます。各カードは上が「なし」、下が「あり」で、同じ動きを同時に再生しています。

カードをクリック（タップ）すると、その場で動作をもう一度実行します。

ゲームフィール
操作したときの手応えや気持ちよさのこと。英語では game feel や juice（果汁）とも呼ばれる。
フレーム
画面が1回更新される単位。1秒に60フレーム。「6フレーム止める」は0.1秒止めること。
入力の猶予
ボタンを押すタイミングが少しずれても、意図どおりに動かしてあげる工夫。遊ぶ人にはほとんど気づかれない。
すべて Canvas 2D と JavaScript で、その場で計算して描いています。
