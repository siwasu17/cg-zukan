サウンド表現図鑑

ゲームの「ピコッ」「ドカーン」や、場面に合わせて変わる音楽は、波の形・高さ・音量の変化・響きの組み合わせでできています。この図鑑の音はすべて、録音したファイルを使わずに、ブラウザの中でその場で合成しています。

音が出ます。最初は音量を控えめにしてください。カードをクリック（タップ）すると鳴り、押している間だけ鳴るカードもあります。左右の違いはヘッドホンだとよく分かります。

周波数（Hz）
1秒間に波がくり返す回数。大きいほど高い音。人の耳に聞こえるのはおよそ 20Hz〜20000Hz。
倍音
基本の高さの2倍・3倍…の周波数の成分。どの倍音がどれだけ含まれるかで音色が決まる。
エンベロープ
音が鳴り始めてから消えるまでの、音量や高さの時間変化のこと。
すべて Web Audio API で音をその場で合成し、Canvas 2D で描いています。音声ファイルは使っていません。
