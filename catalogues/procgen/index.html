Procedural generation catalogue

自動生成図鑑

ゲームの地形やダンジョン、迷路、植物、名前までを、人が1つずつ作るのではなく「規則と乱数」から自動で作る技法を集めました。同じ規則でも乱数の種（シード）を変えるたびに違う結果が生まれ、同じ種からは何度でも同じ結果を作り直せます。

各カードの「作り直す」を押すと、乱数の種を変えて新しく生成します。作る過程そのものを動かして見せているカードもあります。

乱数の種（シード）
乱数の出発点になる数。同じ種からは毎回同じ乱数の並びが出るので、同じ世界を再現できる。
ノイズ
なめらかにつながった乱数。地形の起伏や雲の模様など、自然なばらつきの元になる。
手続き型生成
英語では procedural generation。手順（プログラム）で中身を生み出すこと。
すべて Canvas 2D と JavaScript で、その場で計算して描いています。「作り直す」を押すと、乱数の種が変わって別の結果になります。
