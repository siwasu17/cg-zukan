物理シミュレーション図鑑

ゲームの中でものが落ちたり、揺れたり、崩れたりするのは、1フレームごとに「力から速さを、速さから位置を」少しずつ計算し直しているからです。ここでは、ボールの跳ね返りから布やロープ、ぐにゃぐにゃの体、砂や水まで、自作の小さな物理計算で動かして並べました。

多くのカードは、マウス（指）で物をつかんで引っぱったり、投げたりできます。

物理エンジン
重力や衝突、つながりなどの計算をまとめて行うプログラム。ゲームの中の「ものの動き」の大部分を担う。
時間の刻み（dt）
1回の計算で進める時間。小さいほど正確だが、計算の回数が増えて重くなる。
拘束（コンストレイント）
「この2点の距離は一定」のような決まりごと。毎フレーム、決まりを守るように位置を直す。
すべて Canvas 2D と JavaScript の自作の物理計算で動いています。
