弾幕図鑑

画面を埋めつくす弾幕も、1発1発は「どこから・どの向きに・どの速さで」撃つかの3つの数字で決まっています。あとは「いつ撃つか」と「撃った後にどう変えるか」の規則の組み合わせです。ここでは基本の撃ち方から、それを重ねたボス戦風の弾幕、裏側の仕組みまでを並べました。

カードの上にカーソルを置く（スマホではタップする）と、画面下の自機がついてきます。自機を狙う弾幕は、動かすと撃ってくる向きが変わります。球体マテリアル図鑑と毛と流体の球体図鑑の続編です。

自機
プレイヤーが操作する機体。画面下の小さな機体で、中央の白い点が本当の当たり判定。
フレーム
画面が1回更新される単位。ここでは1秒に60フレームで、弾は毎フレーム少しずつ進む。
角度と速さ
弾の動きは「向き」と「1フレームに進む距離」の2つで表す。右が0°、下が90°。
すべて Canvas 2D と JavaScript で、その場で弾を計算して描いています。同じ乱数の種を使っているので、「最初から」を押すと毎回同じ弾幕が再生されます。
