Pixel art & 2D techniques

ドット絵・2D技法図鑑

使える色も画素も少なかった時代のゲームは、その制約の中で驚くほど豊かな表現を生み出しました。色を差し替えて敵の種類を増やす、色を回して水を流す、点の並べ方で中間色を作る、背景を何層にも分けて奥行きを出す。今のドット絵ゲームにも受け継がれている技法を集めました。

キャラクターや背景は、すべてページの中の小さなデータから描いています。画面のドットは拡大して表示しています。

ドット（ピクセル）
画面を作る最小の四角。ドット絵は、この四角を1つずつ置いて絵を描く。
パレット
その絵で使う色の一覧。絵は「何番の色か」だけを覚えていて、色そのものは一覧から引く。
スプライト
背景の上を動くキャラクターなどの小さな絵。背景とは別に描いて重ねる。
ドット絵もすべてページ内のデータから描いています。Canvas 2D と JavaScript でその場で計算しています。
