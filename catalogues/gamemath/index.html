Game math catalogue

ゲームの数学図鑑

キャラクターが敵のほうを向く、弾がまっすぐ飛ぶ、カメラがなめらかについてくる、剣が当たったかを調べる。ゲームの動きの下では、いつも小さな数学が働いています。ここでは、ベクトル・角度・補間・当たり判定の基本を、矢印や数字を画面に出しながら動かしました。

多くのカードは、丸い点をマウス（指）でドラッグして動かせます。触ると自動の動きが止まり、「最初から」で元に戻ります。

ベクトル
向きと長さをもった量。(x, y) の2つの数で表し、矢印で描く。位置の差や速さを表すのに使う。
正規化
ベクトルの向きはそのままで、長さを1にそろえること。「向きだけ」がほしいときに使う。
補間
2つの値のあいだを、割合 t（0〜1）で埋めること。t = 0 で始まり、t = 1 で終わる。
画面の座標
右が x のプラス、下が y のプラス。数学の教科書とは上下が逆なので、角度は時計回りがプラスになる。
すべて Canvas 2D と JavaScript で、その場で計算して描いています。
