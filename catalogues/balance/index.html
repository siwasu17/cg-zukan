確率とゲームバランス図鑑

ガチャの確率、会心の一撃、ドロップ品、レベルの上がり方、対戦の勝ち負け。ゲームの「運」と「数字の手ごたえ」は、乱数と式の組み合わせでできています。各カードはその場で何千回、何万回と試行をくり返し、グラフが育っていく様子を見せます。1回だけでは見えない確率の姿と、偏りや不公平感を抑えるための工夫を集めました。

グラフ上のつまみ（白い丸）をドラッグすると、確率や回数などの値を変えられます。「作り直す」を押すと、乱数の種を変えて最初から試し直します。

確率と試行probability / trial
くじを1回引くことを「試行」と呼ぶ。確率10%とは、何度も試行したときに約10回に1回当たるということで、次の1回が当たるかどうかは分からない。
期待値expected value
1回あたりに平均して得られる量。会心率25%・2倍なら、ダメージの期待値は通常の1.25倍になる。
分布distribution
結果がどの値にどれくらいの割合で散らばるかを表したもの。この図鑑では棒グラフ（ヒストグラム）で描いている。
すべて Canvas 2D と JavaScript で、その場で計算して描いています。グラフの棒は実際に試した結果、オレンジの線は計算で求めた値です。
