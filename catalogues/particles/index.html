パーティクル・エフェクト図鑑

炎も煙も爆発も魔法も、ゲームのエフェクトの多くは「小さな粒をたくさん出して、少し動かして、消す」という同じ仕組みでできています。違うのは、粒を出す量、寿命、速さ、重力、そして寿命に合わせた色と大きさの変え方です。まず仕組みを分解して見てから、実際のエフェクトを並べます。

カードをクリック（タップ）すると、その場所で発生させたり、もう一度再生したりできます。

パーティクル
エフェクトを作る1つ1つの粒。位置・速さ・寿命・色・大きさを持ち、毎フレーム少しずつ動いて、寿命が来たら消える。
エミッター
粒を出す装置。1フレームに何個出すか、どの範囲から、どの向きにどれくらいの速さで出すかを決める。
加算合成
重なった部分の色を足し算する描き方。重なるほど明るくなるので、光・炎・魔法に使う。
すべて Canvas 2D と JavaScript で、その場で計算して描いています。
